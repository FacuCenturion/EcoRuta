# EcoRuta

Sistema web para visualizar el estado de contenedores inteligentes y apoyar la gestión de recolección de residuos.

## Stack inicial

- React
- TypeScript
- Vite
- Datos simulados en frontend

## Cómo ejecutar

npm install
npm run dev
